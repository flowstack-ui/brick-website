# Contributing

Thanks for helping improve the Brick documentation website.

## Before opening an issue

- Search existing issues first.
- Use the website bug form for reproducible content, visual, interaction,
  accessibility, performance, navigation, or search problems.
- Use the website improvement form for a new visitor need.
- Report vulnerabilities privately according to [SECURITY.md](SECURITY.md).

## Pull requests

Keep changes focused and explain the visitor need. Follow the repository's
local setup and verification commands in the README and package scripts.
Review affected routes at relevant desktop and mobile widths, including
keyboard and focus behavior when interactions change.

By participating, you agree to follow the
[Code of Conduct](CODE_OF_CONDUCT.md).
