# Security Policy

## Supported deployment

Security fixes apply to the current production deployment of the Brick documentation website.
Historical deployments and local forks are not supported.

## Report a vulnerability

Do not open a public issue. Submit a
[private security advisory](https://github.com/flowstack-ui/brick-website/security/advisories/new)
with:

- the affected URL or route;
- the security impact and realistic attack scenario;
- reproducible steps and relevant browser or device details;
- sanitized requests, responses, or screenshots when useful; and
- any suggested remediation or disclosure constraints.

Do not test with real user data or include credentials, tokens, or unrelated
private information. Maintainers will acknowledge the report, validate its
impact, coordinate a fix and deployment when needed, and discuss disclosure
and credit with the reporter.

## Scope

In scope are vulnerabilities in the website code and current deployment.
Content inaccuracies without security impact, harmless version disclosure,
denial-of-service testing, third-party services, and scanner-only findings
without a credible impact or reproduction are generally out of scope.
